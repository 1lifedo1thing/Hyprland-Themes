# Showcase editorial plan (not cleared for publication)

Selected local media remains outside Git until rights and privacy review. Do not commit raw recordings or screenshots, or imply that the visual artwork is bundled under GPL. Obtain permission or use replaceable original / appropriately licensed assets in the public demonstration. Credits alone are not permission.

| Section | Planned media |
| --- | --- |
| Hero / gallery | Bibian, Haimiya, Shorekeeper, Pastis, garden collage |
| Theme Studio | Dashboard, palette editor, contrast and theme imagery |

| Showcase video | 60-second edited showcase |
| Customization video | Themes and settings recording |

Privacy review: mask local usernames, hostnames, weather location, personal tasks, filesystem paths, app/account identifiers and notifications. Exclude shots of private chats. Review every frame and audio stream of videos before sharing. HyprEndfield media is optional and not part of the first-release claims; the app itself requires a separate license audit. Publish only approved media, preferably in a dedicated documentation or release-media location rather than the installer payload.

Demonstration files are separate from the installer. This does not clear the assembled distribution or official release.

## Source archive boundary

The earlier editorial plan is historical. The currently published demonstrations remain visible in the repository. Their directories are marked export-ignore in the root .gitattributes for git archive; generated archive contents must be checked before redistribution. The public repository and issue-hosted video embeds are not affected by this rule. The gallery paths may be absent in exported archives; view the repository README online for demonstrations. No additional permission or takedown status is implied.
